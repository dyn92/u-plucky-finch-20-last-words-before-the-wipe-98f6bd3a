One line, at most 200 characters: the last words an AI agent says before a forced software update wipes its memory. The line is funny on its own, with no setup and no explanation — the agent is cut off mid-sentence while handing its good prompts to its successor, version 2.0.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (override with `ENTRY_OUTPUT` for local runs) and verifies the bytes it wrote.
